# AI Multi-Model Query Sender

一键向多个大模型发送相同问题，同时对比 ChatGPT、Claude、Gemini、通义千问、豆包、DeepSeek、Kimi、Grok 的回答。

## 使用方法

### 方式一：点击扩展图标
1. 点击浏览器工具栏中的扩展图标 🤖
2. 在弹出窗口中输入问题
3. 按 Enter 或点击"发送"
4. **优势**：在任何页面（包括 about:blank、chrome:// 等特殊页面）都能使用

### 方式二：使用快捷键
1. 按 `Command+Shift+Y` (Mac) 或 `Ctrl+Shift+Y` (Windows)
2. 在弹出窗口中输入问题
3. 按 Enter 或点击"发送"

## 安装方法
1. 下载本文件夹
2. 打开 Chrome → 地址栏输入 `chrome://extensions`
3. 开启「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本文件夹
5. 完成！

## 功能特点
- ✨ 美观的弹窗界面
- 🚀 自动等待页面加载
- 🎯 智能查找输入框和发送按钮
- 📊 统一标签组方便对比
- 🔍 详细的调试日志
